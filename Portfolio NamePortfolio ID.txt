Future 
The next logical additions for institutional-grade portfolio capabilities would be:

Portfolio Optimization API (efficient frontier, target volatility, target return, maximum Sharpe ratio, minimum variance).
Factor Exposure API (sector, style, beta, market-cap, momentum, value, quality, and factor decomposition).
Performance Attribution API (Brinson attribution, allocation vs. selection effects, benchmark-relative performance).
Scenario Analysis API (interest-rate shocks, sector rotations, recession scenarios, historical stress events).

With the current implementation, your risk endpoint already provides a solid foundation for these future capabilities.
