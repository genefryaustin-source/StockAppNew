# Sprint L2.4 Verification Checklist

## Analytics

- [ ] Total assignments match the database.
- [ ] Completion rate matches accepted, declined, and expired records.
- [ ] Overdue detection uses UTC.
- [ ] Document aggregation is correct.
- [ ] Tenant aggregation is restricted to super administrators.

## Notifications

- [ ] Assigned acknowledgement notifications include document and version.
- [ ] Overdue notices include the correct due date.
- [ ] Delivery failures are logged.
- [ ] Duplicate reminder suppression is implemented before production.
- [ ] Email addresses are resolved through the user directory.

## Enforcement

- [ ] Enforcement remains disabled during testing.
- [ ] Declined records block only when configured.
- [ ] Overdue records block only when configured.
- [ ] Users can access the acknowledgement page while restricted.
- [ ] Super administrators have an emergency override procedure.

## Scheduled job

- [ ] The systemd service exits successfully.
- [ ] The timer runs at the expected UTC time.
- [ ] The environment file loads.
- [ ] Database connectivity succeeds.
- [ ] Notifications are sent through the configured sink.
