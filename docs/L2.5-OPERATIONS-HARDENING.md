# Sprint L2.5 — Legal Operations Hardening

L2.5 adds production-oriented escalation, override, evidence, deduplication,
and retention controls.

## Capabilities

- Escalation levels for overdue acknowledgements
- Idempotent notification keys
- Manager, tenant-admin, and super-admin escalation hooks
- Temporary legal access overrides
- Required override justification
- Override expiration and revocation
- Evidence package generation
- SHA-256 integrity hash for evidence payloads
- Configurable retention classes
- Legal Operations Control dashboard
- Optional daily escalation timer

## Production requirements

The included override repository is in memory. Before production use,
implement the supplied migration and a SQL-backed override repository.

The escalation job requires:

- a recipient resolver;
- a notification delivery sink;
- persistent notification-key deduplication;
- delivery status recording;
- operational alerting for failures.

## Override governance

Legal access overrides should:

- be limited to super administrators;
- require a documented reason and justification;
- expire automatically whenever possible;
- be visible in compliance reporting;
- create immutable audit events;
- be reviewed periodically;
- never alter or delete the underlying acknowledgement record.
