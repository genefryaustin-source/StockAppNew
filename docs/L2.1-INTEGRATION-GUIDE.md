# Sprint L2.1 — StockApp Enterprise Integration

## Purpose

Sprint L2.1 integrates the Streamlit Legal Portal with the main StockApp,
login page, application footer, role model, audit logging, operations health,
Nginx static publishing, and deployment verification.

## Integration order

1. Replace `modules/legal_portal/` with the L2.1 version.
2. Copy `deployment/` and `manifest/` into the repository root.
3. Apply `integration/app.py.integration.py`.
4. Apply `integration/login_ui.integration.py`.
5. Add navigation entries from `integration/navigation.integration.py`.
6. Connect the optional audit sink.
7. Install the Nginx snippet from Sprint L1.5.
8. Add the deployment block.
9. Test public and authenticated routes.
10. Commit, push, and deploy.

## Public routes

```text
/?page=legal&legal_document=privacy-policy
/?page=legal&legal_document=terms-of-service
/?page=legal&legal_document=risk-disclosure
```

## Static routes

```text
/legal/privacy-policy.html
/legal/terms-of-service.html
/legal/risk-disclosure.html
```

## Audit events

```text
LEGAL_PORTAL_OPENED
LEGAL_DOCUMENT_VIEWED
LEGAL_ACCESS_DENIED
LEGAL_DOCUMENT_DOWNLOADED
LEGAL_DOCUMENT_PUBLIC_OPENED
LEGAL_DOCUMENT_PRINTED
LEGAL_SEARCH
LEGAL_EXPORT
```

The default audit sink writes structured events to the Python logger.
Replace it with the existing StockApp audit service when wiring the module.

## Important limitation

This package includes patch-ready integration examples because the current
production `app.py`, navigation module, and audit repository were not supplied
with this request. Apply the examples at the matching locations in the current
repository rather than replacing those application files wholesale.
