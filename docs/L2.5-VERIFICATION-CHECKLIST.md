# Sprint L2.5 Verification Checklist

## Escalation

- [ ] Escalation level changes at configured day thresholds.
- [ ] Notification keys are stable and unique.
- [ ] Duplicate escalation notices are suppressed.
- [ ] Recipient resolution respects tenant boundaries.
- [ ] Notification failures are recorded.

## Overrides

- [ ] Only super administrators can create overrides.
- [ ] Justification is mandatory.
- [ ] Expired overrides no longer bypass enforcement.
- [ ] Revoked overrides no longer bypass enforcement.
- [ ] Override creation and revocation emit audit events.
- [ ] Underlying acknowledgement records remain unchanged.

## Evidence

- [ ] Evidence packages include versions, reviews, and acknowledgements.
- [ ] Filters correctly limit user, tenant, and document scope.
- [ ] SHA-256 evidence hash is generated.
- [ ] Export timestamps use UTC.
- [ ] Sensitive evidence access is logged.

## Retention

- [ ] Retention periods receive counsel approval.
- [ ] Legal holds override ordinary deletion.
- [ ] Purge jobs preserve immutable evidence where required.
- [ ] Archived records remain readable.
