# Sprint L2.4 — Legal Compliance Operations

L2.4 adds compliance analytics, overdue monitoring, notification hooks,
acknowledgement enforcement controls, and scheduled compliance jobs.

## Capabilities

- Completion and acceptance metrics
- Overdue acknowledgement detection
- Document-level aggregation
- Tenant-level aggregation
- CSV-ready acknowledgement export
- Notification event models
- Email-provider integration hook
- Daily compliance job
- Optional systemd timer
- Configurable access enforcement

## Enforcement warning

`enforcement_enabled` defaults to `False`.

Do not enable blocking behavior until:

- qualified counsel approves the required documents;
- acknowledgement assignment is persistent and verified;
- due dates and escalation rules are documented;
- the user interface provides a clear review and response path;
- account recovery and administrator override procedures exist;
- accessibility has been tested;
- enterprise customers have been notified.

## Scheduled job installation

```bash
sudo cp deployment/stockapp-legal-compliance.service       /etc/systemd/system/

sudo cp deployment/stockapp-legal-compliance.timer       /etc/systemd/system/

sudo systemctl daemon-reload
sudo systemctl enable --now stockapp-legal-compliance.timer

systemctl list-timers stockapp-legal-compliance.timer
```

The supplied job logs notifications by default. Connect the notification sink
to the application's email provider before relying on external delivery.
